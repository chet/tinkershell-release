# tinkershell releases

Public binaries for **tinkershell**: a home for tmux sessions, terminals and coding agents.
The application source repository remains private during development. This repository
contains release notes and binary downloads; its automatic source archives contain
only these public repository files.

- `tinkershell-server`: the tmux host service, with its own private tmux runtime.
- `tinkershell-gateway`: shared workspaces, routing and web/native access.
- `tinkershell`: the terminal interface, distributed in the `tinkershell-tui` package.

The first binary release is being qualified. Installation instructions and the
product tour are at [tinkershell.io](https://tinkershell.io).
